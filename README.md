# AI몬스터

초등 5~6학년용 **AI 윤리 교육 게임**입니다.
저작권·개인정보·허위정보를 몬스터로 만들어, 상황 문제를 풀어 붙잡고 정화합니다.

### ▶ 바로 해보기 — https://legoschool.github.io/aimon/

설치 없이 바로 열립니다. 학생들에게는 이 주소만 알려주면 됩니다.

## 1. 실행하는 법

인터넷이 되면 위 주소로 바로 들어가면 되고,
**교실에 인터넷이 없으면 `index.html` 파일을 더블클릭하세요.** 그게 전부입니다.

- 설치·인터넷·계정 필요 없음
- 이미지 파일이 하나도 없어서(그림을 전부 코드로 그림) 오프라인 교실에서도 그대로 돌아감
- 폴더째 USB에 담아 학생 컴퓨터에 복사해도 됨
- 진행 상황은 그 컴퓨터의 브라우저에 저장됨 (다른 컴퓨터로 옮겨가지 않음)

> `serve.js` 는 개발·점검용입니다. 수업에는 필요 없습니다.

## 2. 어떻게 하는 게임인가

```
데이터숲에 서 있는 그림자몬에게 다가가 부딪힘
        ↓
판단 도구를 골라 상황 문제를 풀기
   맞히면 몬스터가 약해지고, 틀리면 내 신뢰도가 깎임
        ↓
장악력 30% 이하 + 정답률 60% 이상이면 판단볼을 던질 수 있음
        ↓
잡으면 정화 → 그림자몬이 가치몬으로 바뀌어 도감에 등록
```

**핵심**: 충분히 이해해야만 잡을 수 있습니다. 정답률 60%가 안 되면 볼을 던질 수 없어요.

**몬스터는 맵 위에 보입니다.** 확률로 튀어나오지 않으니 헤매는 시간이 없고,
**선생님이 화면만 봐도 진도를 알 수 있습니다** — 남은 몬스터가 그림으로 보이니까요.
놓친 몬스터는 같은 숲의 다른 자리로 옮겨가 다시 도전할 수 있습니다.

### 박사님 의뢰 (미션)
화면 위 **[의뢰]** 에 할 일 6가지가 있습니다. 달성하면 판단볼을 받습니다.

| 의뢰 | 조건 | 보상 |
|---|---|---|
| 첫 정화 | 아무거나 1마리 | 기본판단볼 2 |
| 만든 사람의 몫 | 저작권 2마리 | 근거볼 1 |
| 친구를 지키는 법 | 개인정보 2마리 | 근거볼 1 |
| 진짜를 가려내는 눈 | 허위정보 2마리 | 근거볼 1 |
| 확실한 판단 | 3마리 + 정답률 80% 이상 | 확신볼 1 |
| 모두 정화 | 6마리 전부 | — |

화면 맨 위에 **지금 할 일**이 한 줄로 계속 떠 있어서, 아이가 무엇을 해야 할지 헷갈리지 않습니다.
40분 수업이면 앞의 세 개까지가 적당합니다.

> 의뢰는 `data/missions.js` 에서 고칠 수 있습니다. 수업 시간에 맞춰 개수를 줄여 쓰세요.

### 판단 도구 4개 (= 상성)

| 도구 | 강함 ×1.5 | 약함 ×0.5 |
|---|---|---|
| 🔍 출처확인 | 허위정보 | 저작권 |
| ⚖️ 권리존중 | 저작권 | 개인정보 |
| 🤝 책임사용 | 개인정보 | 허위정보 |
| 🧠 비판적사고 | — (전부 보통) | 없음 · 틀려도 피해 절반 |

앞의 셋은 가위바위보처럼 돌고, 🧠비판적사고는 **모를 때 고르는 안전패**입니다.

### 몬스터 6종

| Lv | 그림자몬 | → 정화 | 배우는 것 |
|---|---|---|---|
| 5 | 복붙몬 | 출처지기 | 내 말로 다시 쓰고 출처 밝히기 |
| 6 | 막올림몬 | 동의지기 | 올리기 전에 찍힌 사람에게 묻기 |
| 7 | 그럴싸몬 | 확인지기 | 두 군데 이상에서 교차 확인 |
| 8 | 슬쩍몬 | 허락지기 | 만든 사람이 정한 조건 확인 |
| 9 | 술술몬 | 비밀지기 | 꼭 필요한 정보만 최소한으로 |
| 10 | 가짜몬 | 진실지기 | 진짜와 가짜를 가려내기 |

가짜몬(보스)은 **3마리 이상 정화해야** 나타납니다.

수업이 안 되기 때문입니다. 필요하면 켜세요. 설정은 그 컴퓨터에 기억됩니다.

소리도 음원 파일이 아니라 코드로 그 자리에서 만듭니다. 받을 파일이 없습니다.

## 4. 수업에서 쓰는 법

### 여러 학생이 한 컴퓨터를 쓸 때
**이름을 다르게 적으면 각자 따로 저장됩니다.** 앞 학생 기록을 덮어쓰지 않아요.

- 처음 하는 이름 → 새로 시작
- 전에 하던 이름을 그대로 적으면 → **이어서 하기**
- 타이틀 화면 아래 목록에서 이름을 눌러도 이어서 할 수 있습니다
- 목록의 **[지움]** 으로 기록을 지웁니다

### 반 전체를 한눈에 보기 (선생님용)
타이틀 화면 **[반 전체 기록]**

- 참여 학생 수, 반 평균 정답률, 평균 정화 수
- **반 전체가 어느 주제를 어려워했는지** — 다음 수업에서 짚을 지점
- 학생별 표 (정화 수 · 정답률 · 푼 문제 수 · 마지막 날짜)
- 이 화면도 그대로 인쇄됩니다

> 기록은 **그 컴퓨터의 브라우저**에만 남습니다. 다른 컴퓨터로 옮겨가지 않아요.
> 컴퓨터를 바꿔 가며 수업한다면 학생마다 같은 자리에 앉게 해 주세요.

### 학생 개인 기록 인쇄하기
맵 화면 오른쪽 위 **[기록]** → **[인쇄하기]**

인쇄물에 담기는 것:
- 정화한 몬스터 수, 전체 정답률
- **주제별 정답률** (저작권 / 개인정보 / 허위정보)
- **판단 도구별 정답률** — 어떤 관점이 약한지 보임
- 성적에 맞춘 진단 문구
- **한 번이라도 틀린 문제 전체** (지문·정답·해설 포함)

마지막 항목이 그대로 복습 학습지가 됩니다.

### 수업 흐름 예시 (40분)
1. (5분) 게임 소개, 이름 입력
2. (25분) 자유 탐험 — 6마리 정화 목표
3. (10분) [기록] 인쇄 → 틀린 문제 함께 읽기

### 다시 시작하려면
타이틀 화면에서 **[새로 시작하기]** 를 누르면 기록이 초기화됩니다.

## 5. 문제를 우리 반에 맞게 고치기

**`data/questions.js`** 파일 하나만 고치면 됩니다.

```js
{
  id: "cr_01",
  type: "copyright",        // copyright | privacy | disinfo
  tool: "respect",          // verify | respect | ownership | critique
  level: "easy",            // easy | hard
  situation: "모둠 발표 자료를 만들다가, 인터넷에서 ...",
  question: "이럴 때 가장 알맞은 행동은?",
  options: ["...", "...", "...", "..."],
  answer: 2,                // 정답 번호 — 0부터 셈! 위 예시는 세 번째
  explanation: "맞히든 틀리든 항상 보여주는 해설",
  wrongHint: "틀렸을 때만 덧붙는 한마디",
}
```

⚠️ **`answer` 는 0부터 셉니다.** 첫 번째 보기가 정답이면 `0` 입니다.

### 지켜야 할 것
- 한 속성(`type`) 안에서 **도구(`tool`)마다 최소 2문항**은 남겨 두세요.
  그 도구의 문제가 다 떨어지면 게임에서 그 버튼이 잠깁니다.
- 보기는 반드시 4개입니다.

난이도를 바꾸려면 **`src/equations.js`** 의 `BALANCE` 값만 고치면 됩니다.
게임의 모든 수식이 그 파일 하나에 모여 있습니다.

## 6. 설계에서 신경 쓴 것

**틀린 문제는 다시 나옵니다.**
맞힌 문제만 빠지고 틀린 문제는 문제 주머니로 돌아갑니다. 해설을 방금 읽었으니
다시 만나 맞히고 넘어가라는 뜻입니다. 이 규칙이 없으면 못 맞히는 아이일수록
문제가 빨리 떨어져서 *실력이 아니라 문제가 없어서* 지게 됩니다.

**문제만 가르치지 않고 대안을 짝으로 가르칩니다.**
복붙몬을 잡으면 출처지기가 됩니다. "하지 마라"가 아니라 "대신 이렇게 하라"가
도감에 남습니다. 여섯 쌍 모두 반대말로 맞춰져 있습니다.

**허락지기와 동의지기가 비슷한 건 일부러입니다.**
둘 다 "남의 것에 함부로 손대지 않는다"는 같은 뿌리이고, 차이는 **누구에게 구하느냐**입니다.
허락지기는 **만든 사람**에게(저작권), 동의지기는 **찍힌 사람**에게(초상권).
헷갈리는 지점을 그대로 학습 포인트로 씁니다.

## 7. 저작권

이 게임은 **전부 새로 만들었습니다.**
몬스터 이름·그림·문제·해설·음악적 요소 어느 것도 다른 작품에서 가져오지 않았습니다.
그림은 이미지 파일이 아니라 글자 격자로 코드 안에 직접 그렸습니다
(`data/monsters.js` 를 열면 그림 모양이 눈에 보입니다).

저작권을 가르치는 게임이 저작권을 지키지 않으면 수업에서 할 말이 없기 때문입니다.
수업 시간에 "이 게임도 남의 것을 베끼지 않고 만들었다"고 말할 수 있습니다.

## 9. 자주 나올 질문

**Q. 학생이 이름을 잘못 적고 시작했어요.**
타이틀 목록에서 그 이름의 **[지움]** 을 누르고 다시 시작하면 됩니다.

**Q. 같은 이름이 두 명이면요?**
한 사람으로 취급돼 기록이 합쳐집니다. `민서1`, `민서2` 처럼 구분해 주세요.

**Q. 기록을 다른 컴퓨터로 옮길 수 있나요?**
지금은 안 됩니다. 인쇄가 유일한 방법입니다.

**Q. 소리가 안 나요.**
브라우저는 화면을 한 번 누르기 전에는 소리를 못 내게 막습니다.
아무 버튼이나 한 번 누르면 그때부터 납니다.

**Q. 게임이 너무 쉬워요 / 어려워요.**
`src/equations.js` 의 `BALANCE` 에서 `baseDamage`(한 문제당 위력)와
`wrongPenalty`(오답 시 깎이는 신뢰도)를 조절하세요.
