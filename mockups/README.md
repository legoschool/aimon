# 엔딩 확장 목업: 나의 다음 선택

`ending-reflection.html`을 열면 실제 게임의 가치몬 그림을 사용한 독립 목업이 나온다. 세 곳을 완료한 뒤를 가정한다. 가상 여정이다. 게임 저장본을 읽거나 시트에 전송하지 않는다.

## 무엇을 남기는가

| 구성 | 학생이 하는 일 | 교사가 읽을 근거 |
|---|---|---|
| 장면과 동료 | 동의지기, 스스로지기, 기다림지기 중에서 고르고 자신의 행동을 쓴다 | 상황을 자기 행동으로 옮겼는가 |
| 선택의 이유 | 그 행동이 누구에게 어떤 결과를 줄지 쓴다 | 영향을 받는 사람과 결과를 연결했는가 |
| 생각을 바꿀 조건 | 새 사실이 나타나면 판단을 어떻게 바꿀지 쓴다 | 확인할 사실과 판단의 관계를 설명했는가 |
| 실천 약속 | 언제, 무엇을 할지 쓴다 | 나중에 해봤는지 돌아볼 행동인가 |

가장 무게를 둔 부분은 이유와 조건이다. 핵심이다. 다짐 문구만 고르게 하면 학생이 무엇을 생각했는지 구별하기 어렵다는 설계 판단에서 두 칸을 나눴다. 학습 효과가 검증됐다는 뜻은 아니다.

## 결과물과 보상

기록장에는 학생의 문장, 별명, 선택한 가치몬을 담는다. 정답률 순위를 넣지 않는다. 개인 기록이다. 약속 작성 배지는 글을 남겼다는 뜻이며, 사고력이나 윤리 자격을 인증하지 않는다.

후속 기능에서는 다음 수업에 기록장을 다시 열고 해봤는지, 기회가 없었는지, 약속을 바꾸고 싶은지 고르게 한다. 그 경험과 다음 행동을 기록하면 회고 배지를 준다. 성공만 보상하지 않는다. 실천 여부는 학생의 자기 보고라는 점을 교사용 화면에도 표시한다.

## 지금 눌러볼 수 있는 것

가치몬 선택, 세 단계 이동, 직접 입력, 기록장 실시간 미리보기, 예시 채우기, 빈 칸 안내, 작성 배지, 인쇄 버튼을 구현했다. 입력 후 새로고침하면 글은 사라진다. 저장 전이다. 예시로 덮어쓸 때는 확인을 받으며, 완성 후 글을 고치면 다시 작성 중으로 바뀐다.

## 실제 게임에 붙일 때

기존 엔딩과 여정 증서는 유지하고 마지막에 회고를 선택하도록 연결한다. 회고를 건너뛰어도 게임 완료를 취소하지 않는다. 별개다. `src/dex.js`의 `blankSave`에 회고 기본값을 추가하고, 초안·완성본·후속 회고를 나눠 저장한다.

실제 플레이와 연결하려면 현재 저장 중인 누적 정답률 외에 기억할 장면의 문항 ID와 선택한 답을 남기는 구조가 필요하다. 시트 전송은 별도 작업이다. 학생이 쓴 자유문장을 수집할 범위와 교사용 열람 화면을 정한 뒤 서버 버전을 올린다. 현재 v4에는 회고 저장 기능이 없다.

자동 채점은 넣지 않았다. 교사는 구체적인 행동, 영향받는 사람, 선택의 근거, 생각을 바꿀 조건을 읽고 추가 질문을 남길 수 있다. 점수 전이다. 상투적인 문장에는 "누구에게 어떤 일이 생기나요?"처럼 비어 있는 근거를 묻는다.

## 파일

`ending-reflection.html`은 화면 구조, `ending-reflection.css`는 색·간격·모바일·인쇄 모양, `ending-reflection.js`는 예시와 입력 동작을 담는다. 기존 게임과 분리했다. 픽셀 그림은 `data/stageN/monsters.js`와 `src/render.js`에서 가져온다.
