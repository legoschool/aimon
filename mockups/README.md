# 탐험가의 약속 화면

같은 화면을 예시 모드와 실제 저장 모드에서 사용한다. 구분한다. 주소에 매개변수가 없으면 가상 여정이며, 게임이 여는 `mode=game&student=저장키` 주소에서는 해당 학생의 회고를 읽고 저장한다.

## 학생이 남기는 글

상황에서 할 행동, 선택한 이유, 생각을 바꿀 조건, 행동할 시점, 실천 약속을 적는다. 이유가 핵심이다. 완성한 기록장은 선택한 가치몬과 함께 인쇄할 수 있다.

실제 모드에서는 마지막 보스를 정화한 기록을 확인하고 예시 채우기를 숨긴다. 입력한 초안을 이 브라우저에 저장하며, 완성 저장에 성공하면 약속의 문장을 발급한다. 첫 화면에서도 연다. 서버로 자유문장을 보내지 않으며 다른 컴퓨터에서는 이 글을 불러오지 못한다.

## 배지

`badge-pledge.svg`는 책과 펜을 새긴 약속의 문장, `badge-trail.svg`는 발자국과 새싹 문장이다. 작성하면 첫 문장의 색이 바뀐다. 실천 회고는 준비 중이다. 실제 모드에서도 두 번째 배지는 발급하지 않는다.

게임의 영역별 강점·탐구·복습 배지는 `data/personal-badges.js`에서 판정하고 `src/badges.js`에서 학생별로 표시한다. 각각 다르다. 배지를 받았다는 사실은 유지하며 기준과 획득 당시 기록을 함께 보여 준다.

## 고칠 파일

`ending-reflection.html`은 화면 구조, `ending-reflection.css`는 디자인과 인쇄, `ending-reflection.js`는 입력 동작을 담는다. 저장은 분리했다. `src/reflection-store.js`는 최신 명부에서 해당 학생의 회고만 수정하고, 다른 회고 창에서 먼저 수정한 경우 덮어쓰기를 막는다.
